**PROJECT TITLE:**
       #Digital Stress Mirror - mobile usage behavior reflection system
---
####Project Overview
Digital Stress Mirror is a mobile usage behavior reflection system that analyzes screen time, app-switching frequency, and continuous usage patterns to generate a reflection score.
---
####PROBLEM STATEMENT
   Excessive smartphone usage has become a common issue among students and working professionals. Many users spend long hours on mobile devices without realizing the impact on their productivity, mental well-being, and stress levels. Existing screen-time tools mainly provide usage statistics but do not encourage users to reflect on their digital habits. Therefore, there is a need for a system that monitors mobile usage behavior, analyzes patterns such as screen time and app switching, and provides meaningful feedback to help users become more aware of their digital stress and improve their usage habits.
Technologies Used Frontend: HTML,CSS,JavaScript Backend: java DataBase:MySQL
---
### PROJECT OBJECTIVE
- Monitor screen time
- Track app switching
- Calculate reflection score
- Generate daily reports
- Generate weekly reports
---
### Features
- Screen time monitoring
- App switching analysis

- Usage reports
- Stress awareness feedback
